# Политика конфиденциальности VoiceTyping

*Дата вступления в силу: 8 сентября 2026 г.*

VoiceTyping («мы», «программа», «приложение») уважает конфиденциальность пользователей и стремится к максимальной прозрачности в отношении обработки любых пользовательских данных. 

Программа разработана как локальный инструмент для операционной системы Windows, ставящий безопасность и приватность пользователя на первое место.

---

### 1. Обработка аудио и распознавание речи

1. **Режим «Только офлайн (Vosk)»**:
   - Весь процесс захвата звука с микрофона, распознавания и перевода речи в текст происходит **исключительно локально на вашем компьютере**.
   - Аудиопоток не передается через интернет, не сохраняется во внешних базах данных и не покидает пределы вашего устройства.
   - Этот режим работает полностью без подключения к интернету и без VPN.

2. **Режим «Умный гибрид» и «Только облако (Groq Cloud)»**:
   - При активном облачном распознавании аудиозапись кратковременно передается по защищенному шифрованному протоколу TLS/HTTPS напрямую на серверы API (Groq Cloud).
   - Автор и разработчики VoiceTyping **не имеют доступа** к вашему аудиопотоку, не перехватывают его и не содержат промежуточных серверов для сбора ваших разговоров.
   - При сбое сети или блокировке запроса гибридный режим мгновенно переключается на локальный офлайн-движок на вашем ПК.

---

### 2. Работа с буфером обмена и текстом

- VoiceTyping использует системный буфер обмена Windows исключительно для вставки распознанного текста в активное поле ввода целевой программы.
- Сразу после вставки распознанного текста приложение бережно восстанавливает предыдущее содержимое буфера обмена пользователя.
- Приложение **не сохраняет историю набранного текста**, не ведет логирование вводимых символов и не осуществляет функции клавиатурного шпиона (кейлоггера).

---

### 3. Сбор личных данных и телеметрия

- VoiceTyping **не собирает** личные данные: имя, адрес электронной почты, IP-адреса, пароли или местоположение.
- Приложение **не содержит** скрытых трекеров, сторонних рекламных SDK или навязчивых систем сбора аналитики.
- Проверка обновлений выполняется через публичные репозитории GitHub исключительно для сверки номера версии программы.

---

### 4. Хранение настроек на устройстве

- Все параметры программы (выбранная клавиша, тема оформления, локальный API-ключ, прокси) хранятся локально в файле `settings.json` в папке пользователя: `%APPDATA%\VoiceTyping\`.
- При удалении программы через стандартный деинсталлятор данные настройки могут быть полностью удалены по желанию пользователя.

---

### 5. Открытый исходный код

- Исходный код VoiceTyping полностью открыт и доступен для публичного аудита в репозитории на GitHub: [https://github.com/wesiks/VoiceTyping](https://github.com/wesiks/VoiceTyping).
- Любой пользователь или независимый специалист по безопасности может самостоятельно проверить каждую строчку кода программы.
