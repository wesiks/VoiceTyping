## ✨ Особенности

- 🌊 **Живой 5-полосный эквалайзер**: плавно и пластично колышется прямо в такт громкости вашего голоса, а не случайными дерганьями.
- ✍️ **Живая пунктуация на лету**: автоматически расставляет запятые перед союзами (*что, чтобы, когда, если, но, а...*), начинает предложения с большой буквы и поддерживает голосовые команды (*«запятая»*, *«точка»*, *«вопросительный знак»*, *«с новой строки»*).
- 🎨 **5 дизайнерских тем оформления**:
  - 🟠 **Claude Warm** (фирменный теплый терракотовый обсидиан)
  - 🔵 **Cyber Cyan** (неоновый бирюзовый)
  - 🟢 **Emerald Mint** (изумрудный зеленый)
  - 🟣 **Neon Violet** (киберпанк фиолетовый)
  - 🔴 **Ruby Crimson** (рубиновый красный)
- 🔔 **Мягкие гармонические звуки**: деликатные акустические аккорды (Apple-style) вместо резких системных писков материнской платы.
- 🪟 **Не перехватывает фокус** (`WS_EX_NOACTIVATE`): курсор ввода никогда не слетает из активного окна (Telegram, Word, браузер, VS Code).
- 📥 **Системный трей и окно настроек**: приложение аккуратно живет в трее рядом с часами Windows и имеет удобное графическое меню параметров.
- ⚡ **Двойной гибридный движок**: мгновенный оффлайн-превью (Vosk) + эталонная нейросетевая пунктуация за 0.2 сек (Groq Whisper-large-v3).

## 🚀 Быстрый запуск

### Вариант 1. Запуск из исходников
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/your-username/VoiceTyping.git
   cd VoiceTyping
   ```
2. Создайте виртуальное окружение и установите зависимости:
   ```bash
   python -m venv .venv
   .\.venv\Scripts\pip install -r requirements.txt
   ```
3. Запустите:
   ```bash
   start.bat
   ```
4. При первом запуске откроется окно настроек. Вставьте ваш бесплатный ключ [Groq API](https://console.groq.com/keys) (получение занимает 30 секунд).

## ⌨️ Голосовые команды пунктуации

Во время диктовки вы можете произносить знаки голосом:

| Вы говорите | Что вставляется |
|-------------|:---------------:|
| *«запятая»* | `,` |
| *«точка»* | `.` |
| *«вопросительный знак»* | `?` |
| *«восклицательный знак»* | `!` |
| *«двоеточие»* | `:` |
| *«тире»* | ` — ` |
| *«с новой строки»* / *«новый абзац»* | Перенос строки |

## 📦 Сборка автономного .exe и Установщика

### Сборка в 1 клик:
Запустите файл:
```cmd
build_exe.bat
```
PyInstaller автоматически соберет готовую программу в папку `dist\VoiceTyping\VoiceTyping.exe`. Этот файл можно запускать на любом компьютере без установленного Python!

### Создание установщика (Setup.exe):
1. Установите бесплатный [Inno Setup](https://jrsoftware.org/isdl.php).
2. Нажмите правой кнопкой мыши по файлу `installer.iss` ➔ **Compile**.
3. В папке `dist\installer\` появится красивый готовый инсталлятор `VoiceTyping_Setup.exe` с ярлыком на рабочем столе и поддержкой автозагрузки.
