# VoiceTyping

Голосовой ввод текста для Windows с моментальным распознаванием, живой пунктуацией и плавающим HUD-виджетом.

---

## Возможности

- **Мгновенный ввод в любое приложение**: нажмите и удерживайте клавишу (по умолчанию F8), произнесите фразу и отпустите — текст автоматически вставится в активное окно (Telegram, Word, браузер, мессенджеры, редакторы кода).
- **Плавающий виджет (HUD)**: компактная полупрозрачная панель с динамическим волновым эквалайзером, реагирующим на громкость голоса в реальном времени. Виджет никогда не забирает фокус у активных окон.
- **Интеллектуальная пунктуация**: автоматическая расстановка запятых перед союзами («что», «чтобы», «когда», «если», «но», «а»), капитализация первой буквы предложений и поддержка голосовых команд пунктуации.
- **Шесть цветовых тем**:
  - Claude (теплый терракотовый обсидиан)
  - Cyan (кибер-бирюзовый)
  - Emerald (изумрудно-зеленый)
  - Violet (неоново-фиолетовый)
  - Crimson (рубиново-красный)
  - Amber (янтарно-золотой)
- **Многоуровневая типографика**: встроенные шрифты Manrope (заголовки), Inter (интерфейс и транскрипция) и JetBrains Mono (технические поля и шорткаты).
- **Акустические сигналы**: мягкие гармонические аккорды начала и завершения записи вместо системных звуков Windows (при необходимости отключаются в настройках).
- **Автозапуск и системный трей**: приложение сворачивается в трей рядом с часами Windows и поддерживает запуск при старте системы.

---

## Использование

1. Запустите программу.
2. В любой программе установите курсор в поле ввода.
3. Зажмите и удерживайте **F8** (клавишу можно изменить в настройках).
4. Говорите в микрофон — на экране отобразится виджет с живой транскрипцией.
5. Отпустите клавишу — готовый текст с пунктуацией появится на месте курсора.

Для открытия настроек дважды кликните по значку в системном трее или нажмите правой кнопкой мыши -> «Параметры...».

## Голосовые команды пунктуации

Во время диктовки можно называть знаки препинания словами:

| Вы говорите | Результат |
|---|:---:|
| «запятая» | `, ` |
| «точка» | `. ` |
| «вопросительный знак» | `? ` |
| «восклицательный знак» | `! ` |
| «двоеточие» | `: ` |
| «точка с запятой» | `; ` |
| «тире» / «дефис» | ` — ` |
| «с новой строки» / «новый абзац» | Перенос строки |

## Настройки

В окне параметров доступны:

- **Ключ Groq API**: бесплатный ключ для нейросетевой пунктуации и расшифровки ([получить ключ](https://console.groq.com/keys)).
- **Выбор цветовой темы**: переключение палитры оформления виджета и окон.
- **Клавиша Push-to-Talk**: F8, F4, F7, Caps Lock, Scroll Lock, Pause, Insert.
- **Звуковой сигнал**: включение или отключение звукового сопровождения.
- **Автозапуск**: запуск VoiceTyping вместе со стартом Windows.

## Установка и запуск

### Автономный запуск (без установки Python)
Готовый исполняемый файл находится в папке:
```text
dist\VoiceTyping\VoiceTyping.exe
```
Для удобства создайте ярлык на рабочем столе.

### Запуск из исходного кода
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/<ваш-аккаунт>/VoiceTyping.git
   cd VoiceTyping
   ```
2. Создайте виртуальное окружение и установите зависимости:
   ```bash
   python -m venv .venv
   .\.venv\Scripts\pip install -r requirements.txt
   ```
3. Запустите приложение:
   ```bash
   .\.venv\Scripts\python main.py
   ```

### Сборка в .exe
Для создания автономного исполняемого файла:
```bash
python build.py
```
Готовая сборка появится в каталоге `dist\VoiceTyping\`.
